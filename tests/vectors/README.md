# Generated FF3 vectors

This directory contains two deterministic corpora of 10,000 FF3 and FF3-1
cases each:

- `mysto_clang_fpe.csv` was generated by Mysto's C implementation in
  [`mysto/clang-fpe`](https://github.com/mysto/clang-fpe) at commit
  [`9f75007`](https://github.com/mysto/clang-fpe/tree/9f75007d89981b51ce07a6192c4a3a4571a156fc).
  That implementation is MIT-licensed; the upstream license is available in
  its repository.
- `mysto_python_fpe.csv` was generated by Mysto's Python implementation in
  [`mysto/python-fpe`](https://github.com/mysto/python-fpe) at commit
  [`c51da06`](https://github.com/mysto/python-fpe/tree/c51da06c72ca69af9dde1e18cfb0addfeb8bae96).
  That implementation is Apache-2.0 licensed; its license is available in
  its repository.

The C corpus generator used seed `0x6a09e667f3bcc909`; the Python corpus used
seed `0x510e527fade682d1`. Both sampled AES-128/192/256 keys, 7- and 8-byte
tweaks, radices 2–62, and valid input lengths/domains. The alphabet mapping
matches both implementations:
`0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ`.

CSV columns are variant, key hex, tweak hex, radix, plaintext, and ciphertext.
The corpora are exercised by an ignored integration test, so they do not slow
down the regular test suite. Run both 10,000-vector checks with:

```sh
cargo test --test ff3 -- --ignored extended_mysto_vectors
```

Both corpora were checked against this crate for encryption and decryption;
all 20,000 cases matched.
